# 말풍선 브레인스토밍

아이들과 시뮬레이션 프로그램을 기획할 때 쓰는 브레인스토밍 보드입니다. 나온 말을 입력하면 아이폰 메시지 모양 말풍선으로 떠다니고, '정리하기'를 누르면 같은 화면에서 기획 칸으로 날아가 묶입니다.

디자인은 [thebestwaytosendadm-client](https://github.com/jewonr/thebestwaytosendadm-client)를 따릅니다: SUIT-600 폰트, 자간 -0.5px 말풍선 글자, `#1973DD` / `#DDDDDD` 말풍선, 70px 알약 입력창과 둥근 ↑ 버튼.

## 흐름

1. **모으기** — 입력한 아이디어가 말풍선으로 떠다닙니다. 오래된 것일수록 색이 연해집니다. 누르면 빼기·수정·삭제, 끌면 이동. 여러 줄을 붙여넣으면 줄마다 하나씩 들어갑니다.
2. **정리하기** — 말풍선이 가운데로 모였다가 하나씩 기능·디자인·궁금한 점 칸으로 날아갑니다. 틀린 건 끌어서 다른 칸에 놓고, 쓰지 않을 건 '빼기'로 '빼둔 아이디어' 칸에 모읍니다.
3. 정리한 뒤 새로 입력한 말풍선은 '새 아이디어' 칸에 모였다가, '정리하기'를 누르면 그것만 분류됩니다. '흩어 놓기'를 누르면 다시 떠다닙니다.

작업 내용은 브라우저(localStorage)에 저장됩니다.

## 기획 칸

시뮬레이션 프로그램을 만드는 두 축, 기능과 디자인을 중심으로 나눕니다. 컴퓨터 화면에서는 두 칸이 나란히 놓입니다.

| 칸 | 질문 | 들어가는 것 |
| --- | --- | --- |
| 기능 | 무엇을 할 수 있고, 어떻게 움직일까? | 조작과 선택, "~하면 ~된다" 같은 규칙, 일어나는 일, 점수·성공·실패 |
| 디자인 | 어떻게 보이고, 어떤 소리가 날까? | 등장인물과 배경의 모습, 색, 화면 구성, 버튼과 글자, 소리와 음악 |
| 궁금한 점 | 더 알아보거나 정할 것은? | 아직 정하지 못한 질문 |
| 기타 | 아직 자리를 못 찾은 생각 | 둘 다 아닐 때만 나타납니다. |

빈 칸도 '아직 없어요'로 보여서, 아직 이야기하지 않은 쪽이 한눈에 드러납니다. 칸 목록은 `src/index.html`의 `CATEGORIES`에서 바꿀 수 있습니다.

## 분류 방식

- **claude.ai 아티팩트로 열면** 보는 사람의 Claude 계정으로 Claude가 분류합니다.
- **GitHub Pages에서는** 주제 줄 오른쪽 ‘Gemini 연결’에 각자의 Google Gemini API 키를 넣으면 Gemini가 분류합니다.
  - 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 만들 수 있습니다. 무료 등급에서는 입력한 내용이 Google 서비스 개선에 쓰일 수 있습니다.
  - 키는 그 브라우저의 localStorage에만 저장되고 `generativelanguage.googleapis.com`으로만 보내집니다. 공용 컴퓨터에서는 쓰지 마세요.
  - 모델 이름은 자주 바뀌므로 키로 쓸 수 있는 모델 목록을 먼저 받아, 가장 최신의 안정판 Flash를 씁니다. 무료 한도에 걸리면 Flash-Lite 등 다음 모델로 한 번씩 더 시도합니다(최대 3개).
- 키가 없거나 호출이 실패하면 '?'(궁금한 점), '색·화면·소리'(디자인), '~면·할 수 있어'(기능) 같은 단어로 짐작해서 나눕니다. 틀린 건 끌어서 옮기면 됩니다.

## 파일

| 경로 | 설명 |
| --- | --- |
| `src/index.html` | 원본 (HTML·CSS·JS 한 파일). 고칠 때는 이 파일을 수정합니다. |
| `build.py` | 폰트를 넣어 `index.html`을 만듭니다. |
| `index.html` | 빌드 결과. GitHub Pages가 이 파일을 보여 줍니다. |
| `fonts/` | SUIT SemiBold 웹폰트와 라이선스(SIL OFL 1.1). |

## 수정 후 배포

```bash
python3 build.py
git add -A && git commit -m "..." && git push
```

GitHub 저장소 Settings → Pages에서 **Deploy from a branch**, 브랜치 `main`, 폴더 `/ (root)`가 선택되어 있으면 1분쯤 뒤 `https://jewonr.github.io/bubble-brainstorm/`에 반영됩니다.
